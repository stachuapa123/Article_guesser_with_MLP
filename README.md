# Article predictor 
An experiment project to see how neural networks can predict article in German language.
I used TensorFlow and embedding matrix from fasttext.
The goal of the project is to
- see whether the vector embeddings carry some information about german nouns (they often do not make sense in real life, for example 'girl' has neutral article and not feminine)
- see how basic neural networks can predict german articles using one hot positional encoding.
